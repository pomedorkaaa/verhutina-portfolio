# Портфолио Верхутиной Марии (SMM Manager)

Этот проект представляет собой персональное портфолио SMM-менеджера и креативного директора Марии Верхутиной. Проект выполнен как современное веб-приложение с акцентом на визуальную составляющую, плавные анимации и высокую производительность.

## 🛠 Технологический стек

-   **Фреймворк:** [Minista](https://minista.2nd.it/) — статический генератор сайтов (SSG), использующий React для шаблонизации.
-   **Шаблонизация:** React (JSX) компоненты.
-   **Стилизация:** Tailwind CSS для верстки, PostCSS для обработки стилей.
-   **Анимации:** GSAP (GreenSock Animation Platform) с плагином ScrollTrigger для сложных анимаций прокрутки и переходов между страницами.
-   **Оптимизация изображений:** Sharp.
-   **Шрифты:** Семейство Inter (локальное хранение).

## 🏗 Архитектура проекта

```text
/
├── data/           # JSON данные для динамического контента (кейсы и т.д.)
├── public/         # Статические ресурсы (изображения, шрифты, вендорные JS библиотеки)
│   └── assets/
│       ├── images/ # Фотографии и изображения кейсов
│       └── js/     # main.js (основная логика анимаций) и сторонние скрипты
├── src/            # Исходный код приложения
│   ├── assets/     # Стили (Tailwind, глобальные стили)
│   ├── components/ # Переиспользуемые React компоненты (Layout, Header, Footer)
│   └── pages/      # Страницы сайта (каждый .jsx файл становится отдельной HTML страницей)
│       └── cases/  # Индивидуальные страницы кейсов
├── minista.config.ts # Конфигурация Minista (алиасы, настройки сборки)
├── tailwind.config.js # Конфигурация Tailwind CSS
└── package.json    # Зависимости и скрипты сборки
```

## 🚀 Команды разработки

-   `npm run dev` — запуск сервера разработки с hot-reload.
-   `npm run build` — сборка проекта для продакшена в папку `dist`.
-   `npm run preview` — предварительный просмотр собранного проекта.

## 🎨 Особенности реализации

-   **Система переходов:** В `main.js` реализована кастомная система переходов между страницами с эффектами blur, scale и opacity (аналогично Framer Motion, но на чистом GSAP).
-   **Анимация текста:** Использование `data-split-text` для пословного появления заголовков.
-   **Scroll-Triggered Reveal:** Элементы с атрибутом `data-reveal-up` плавно появляются при скролле.
-   **Cursor Trail:** На главной странице в Hero-секции реализован шлейф из изображений, следующий за курсором.
-   **Оптимизация:** Все изображения используют формат `.webp`, шрифты подключены локально для минимизации внешних запросов.

## 📝 Соглашения по разработке

1.  **Компоненты:** Используйте функциональные компоненты React.
2.  **Стили:** Приоритет отдается классам Tailwind CSS. Для сложных анимаций или специфических стилей используйте `global.css`.
3.  **Анимации:** Новые анимации следует добавлять в `public/assets/js/main.js` или использовать соответствующие `data-` атрибуты.
4.  **Контент:** Данные для новых кейсов рекомендуется выносить в `data/cases.json` (если планируется масштабирование) или создавать новые страницы в `src/pages/cases/`.
